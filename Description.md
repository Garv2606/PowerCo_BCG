# BCG Data Science Virtual Experience (Forage) 🌟

This repository contains my work from the **Boston Consulting Group (BCG) Data Science Virtual Experience** hosted on [Forage](https://www.theforage.com/), focused on customer churn prediction and end-to-end data analysis.

## 📌 Project Overview

The goal of the simulation was to analyze customer churn and provide strategic business insights. This involved building a machine learning model, performing EDA, and preparing a concise business report.

## 🧠 What I Did

- 📊 **Customer Churn Analysis**: Identified key client attributes and designed a structured investigation approach to understand churn behavior.
- 🐍 **Data Analysis with Python**: Used **Pandas** and **NumPy** for data cleaning, exploration, and transformation.
- 📈 **Visualization**: Applied **Matplotlib** and **Seaborn** to create insightful plots and trend visualizations.
- 🌲 **Machine Learning Model**: Developed and tuned a **Random Forest classifier** to predict customer churn, achieving **90.3% accuracy**.
- 📝 **Executive Summary**: Compiled findings into a business-focused summary with actionable insights.
- 📊 **Power BI Analysis**: Supplemented analysis using Power BI dashboards for interactive exploration and presentation.

## 🛠️ Tech Stack

- Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn)
- Jupyter Notebook
- Power BI
- Git & GitHub

## 📈 Results

- Achieved a **90.3% accuracy** on churn prediction
- Delivered actionable insights to support business decisions
- Automated and visualized the entire analysis workflow
